> Исторический черновик · Статус: **архив** (устаревший материал; скорректирован решением **Р6**, STATUS.md и `docs/research/12` §12.2).

Алгоритм: «Извлечение фактов»
Назначение: превратить сообщение в структурированные знания об авторе.
Триггер: в очередь добавлено новое сообщение.
Вход: сообщение, хвост истории сессии, активные факты об авторе.
Выход: 0..k новых/изменённых фактов {субъект, предикат, объект, полярность,
       уверенность, ссылка на сообщение-источник, интервал действия}.
Шаги (человеческим языком, без кода и имён API):
  1) Собрать контекст: сообщение + последние N сообщений сессии.
  2) Запросить у LLM-провайдера структурированный ответ по JSON-схеме:
     список кандидатов-фактов.
  3) Для каждого кандидата найти похожие активные факты (векторный поиск +
     фильтр по субъекту).
  4) Почти совпадающий → обновить уверенность/интервал; противоречащий →
     старый пометить «вытеснен», новый связать с ним обратной ссылкой.
  5) Записать: факты — в реляционное хранилище, эмбеддинги — в векторное,
     связи — в граф.
Инварианты: факты не удаляются физически; у каждого факта есть провенанс;
  операции идемпотентны по (message_id, attempt).
Пограничные случаи: невалидный JSON от LLM (ретраи → карантин); пустой ответ;
  дубликат сообщения; неизвестный язык.
