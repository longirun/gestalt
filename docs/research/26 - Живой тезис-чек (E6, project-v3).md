## 4. Диагноз звеньев

### 4.1. Write-time: экстракция

Три разные моды отказа одного батч-экстрактора (промпт `ExtractionPrompt.SYSTEM`, 20 реплик / 2000 токенов):

1. **Недоизвлечение плотных батчей** — L1-13165: msg 12933 (буллет-список «Ключевые факты») дал 2 факта; @Transient-буллет не выдан — токен отсутствует во всех сырых ответах экстрактора за ран. Rule 10 («Prefer 0 facts over noise») консервативна; факт материализовался только из truth-реплики (13169).
2. **Потеря идентификаторов в парафразе** — L1-13716: из msg 12765 извлечено 7 фактов, включая «audit fields are redundant» — statement без перечня полей (createdBy/…/updateTs): семантика есть, дискретный токен слит в обобщение.
3. **Поздняя материализация** — L1-14563: «basic» в сырце ×8 до M; факт сформулирован только из 14571 (> M).

Побочные дефекты: факт с пустым statement (57ab727c, evidence [12715, 12719, 12765]); дедуп-конфликты — 120 журнальных записей за ран (конфликт = журнал + INSERT отдельной строкой, факты не теряются — DedupPipeline), но 25 конфликтов на одном якоре `(user, code_style_preference)` = зоопарк синонимичных объектов → разбухание constructs.

## 5. Заключение по ассерту и правки

Ассерт тезис-чека (`lift > 0`, спека 28) **не выполнен** (−4 pp, p = 1.0) — условный no-go в терминах §4.2 спеки 28: правка диагностированного звена до следующего рана. Диагноз: не «память бесполезна», а два отсутствующих зуба конвейера — write-time гарантии деталей и read-time селекция; метрика при этом сама шумная (10/17 both-fail — шум).

Предлагаемые правки до следующего рана (решение за владельцем):

1. **(write)** Правило verbatim-идентификаторов в промпт экстракции (имена полей, аннотации, IP, пути — сохранять дословно); опция two-pass (черновой список → фильтр); фикс пустых statement при вставке.
2. **(read)** Top-K селекция digest по embedding-похожести триггер↔факт (embeddings уже материализованы); w/reinforcement — tie-break. С врезкой селекции её параметры (embedding-модель/размерность, top-K, порог, tie-break) входят в `answer_fp` (28 §5.2.3): их смена — перезапись answers новым run'ом того же эксперимента, слепки переиспользуются; аналог на уровне ядра — спека 29 §2 (смена модели = явная миграция с пере-эмбеддингом).
3. **(датасет) — выполнено 19.09 (§2.1)**: выбраковано 7, добавлено 4 (И2+И4 проверены), 3 перемаркировано; проверка вхождения must-токена в корпус до M — кандидат в протокол разметки (28 §6); парафраз-точки — ярус судьи (полный ярус, вне smoke).
4. **(дедуп)** Словарь объектов для якорей предпочтений (зоопарк `code_style_preference`).
