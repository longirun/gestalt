# Gestalt — 13: Таксономия процессов памяти

> 2026-09-04 · Источник: закрытие нити Н1 · Статус: **канон** (**Р18**; STATUS).
> Дополняет: `06 - Концептуальный фундамент.md` §Q2 (фазы памяти), `09 - Construct.md` §4 (жизненный цикл конструкта), `10 - Проекты и радиус применимости.md` §3.4 (жизненный цикл факта).

## 1. Принцип именования

- Имена процессов — **герундии**: длительность и процесс, а не персонаж-исполнитель («кто-то делает» → «идёт процесс»).
- Каждое имя — психологический термин с **теоретической опорой**; псих-метафоры официальны в документации и разговоре.

## 2. Триада write-path

| Процесс | Каденция | Синоним | Содержание | Теория |
|---|---|---|---|---|
| **Encoding** | секунды | extraction, fast path | батч-экстракция фактов (1 LLM-вызов на батч); дедуп, усиление, surprisal — детерминированные (Р6) | кодирование (Тульвинг) |
| **Dreaming** | часы | consolidation, slow path, «сон» | supersession, противоречия, лифт scope, ко-подтверждение, пост-мортем закрытых сессий | консолидация во сне |
| **Gestalting** | дни/недели | induction, формирование схем | emerging→active оси; position детерминирован, LLM — только именование оси (Р5); портрет | схемы Бартлетта / Пиаже |

Триада рассказывает историю: **кодируем → спим → собираем гештальт**.
Gestalting — вершина конвейера: портрет как целостный гештальт — имя проекта замыкает конвейер.

Каденции — свойство расписания исполнения, не концепции.

## 3. Reconciliation (фон)

Сверка вычислимого предиката с хранимым состоянием + самовосстановление (lease + backoff + poison-изоляция, Р10): материализация смерти сессий (`closed_at`), TTL-свипы, перестройка PortraitSnapshot по точке отсечки (`14`, **Р19**). Инженерный канон (reconciliation loop, controller pattern) — псих-опоры не требует и не ищет.

## 4. Read-path — вне таксономии процессов

Сборка контекста и синтез ответа — не фоновые процессы с каденциями, а **per-request API-слой**: контракт `ContextProducer` с конфигурируемыми стратегиями — snapshot-быстро / LLM-микс / точный агентный (выбор хоста: скорость vs точность vs баланс). Архитектура — Н5. Snapshot — канон (`14`, **Р19**): **v1 read-path = слепок + детерминированный WORLD-recall, без LLM**; LLM-стратегии (микс, агентный) — Н5, вне v1.

## 5. Отвергнутые кандидаты (история решения, Н1)

| Кандидат | Почему отвергнут |
|---|---|
| Deriver / Deriving (Honcho) | не псих-термин («вывод мыслей»), теоретической опоры нет |
| Perceiving | гештальт-точен, но семантически мимо: перцепция — сенсорный вход, у нас — извлечение смысла из уже полученного текста |
| Distilling | ML-ассоциация (model distillation), не психология |
| `-er`-имена (Extractor / Consolidator / Inductor) | персонажи-исполнители; канон — процессы (герундии) |
| Harmonizing (для сверочного контура) | «приведение к гармонии» не отражает сверку desired vs actual; принят инженерный канон Reconciliation |
