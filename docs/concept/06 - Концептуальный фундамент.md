# Gestalt — концептуальный фундамент (над-уровень)

> 2026-09-03 · Источник: обсуждение концепции · Статус: **канон** — фундамент принят (**Р2**, **Р4**, **Р12**; STATUS); словарь канона — §8 (**Р22**).
> Конвенция: идеи, отсутствующие в карточках/ТЗ/05, помечены `[ПРЕДЛОЖЕНО]`.

## 1. Зачем этот документ

Это фундамент Gestalt: теоретическая рамка, из которой выводится архитектура. Метод — идти к источникам
(когнитивная наука, психология личности, инженерия знаний) и выводить решения из них, а не скрещивать
готовые системы («слон с носорогом»).

Документ задаёт:

- карту дисциплин-источников и заимствований (§2);
- объединяющую рамку — три ортогональных вопроса: что помнить, как помнить, как познавать человека (§3);
- ключевой выбор модели личности — идиографическое ядро + номотетические проекции (§5, **Р4**);
- профиль как предиктивный инструмент, не диагноз (§6, Деннет);
- канон терминологии проекта (§8, **Р22**).

## 2. Карты дисциплин: кто что заимствует

| Дисциплина | Ключевые теории | Кто заимствует |
|---|---|---|
| Психология памяти | Тульвинг: эпизодическая/семантическая/процедурная память; Бартлетт: память = **реконструкция по схемам**, не воспроизведение; консолидация во сне | Honcho (Dreamer — метафора без теории) |
| Психология личности | Теория черт (Big Five) — **номотетика**: всех меряем одной сеткой; Келли: personal construct theory — **идиография**: у каждого своя система личностных конструктов; Мишель: поведение = личность × ситуация | никто — профиль Honcho примитивен именно поэтому |
| Social cognition | Theory of mind; интенциональная позиция Деннета: модель пользователя — **предиктивный инструмент**, а не истина/диагноз | Honcho (как лозунг) |
| Инженерия знаний | Онтологии, схемы, символьное vs субсимвольное | cognee (целиком; про знания о документах, не про человека) |

Разделение ролей: **Honcho = когнитивные метафоры без KR-дисциплины; cognee = KR без человека.**

## 3. Объединяющая рамка

Память ИИ-агента = **экстернализованная когнитивная архитектура** (линия ACT-R / SOAR).
Три ортогональных вопроса (независимые оси — «слон с носорогом» не возникает):

### Q1. Что помнить? (онтология содержания)

- эпизодика: диалоги → `Message`;
- семантика: факты о мире, включая юзера как объект (биография, состояние) → `Fact/WORLD`;
- выводная модель человека — **отдельный класс** (social cognition), ни эпизодика ни семантика → `Fact/PSYCHE` + `Portrait`.

Honcho смешивает все виды знаний в один недифференцированный тип выводов; здесь структура сущностей
`Message` / `Fact/WORLD` / `Fact/PSYCHE` + `Portrait` прямо следует таксономии Тульвинга.

### Q2. Как помнить? (динамика памяти)

Кодирование → консолидация → забывание → реконструкция. Каденции процессов ложатся ровно:

| Процесс | Фаза | Теория |
|---|---|---|
| Encoding (секунды) | онлайн-кодирование | кодирование (Тульвинг) |
| Dreaming (часы) | системная консолидация | консолидация во сне |
| Gestalting (дни/недели) | формирование схем | схемы Бартлетта / Пиаже |

Имена процессов — канон (**Р18**, док `13 - Таксономия процессов памяти.md`).

Соответствия в терминах Пиаже:
- обновление уверенности при похожем факте = **ассимиляция** (Пиаже);
- supersession-цепочка («вытеснен» + обратная связь) = **аккомодация** (схема перестроилась).

### Q3. Как познавать человека? (модель личности)

Настоящая концептуальная развилка (см. §5).

## 4. Почему название проекта теоретически точно

Гештальтпсихология (из неё вырос Бартлетт): портрет = **целое, реконструируемое из следов**,
большее суммы фактов — а не «выборка фактов с high-confidence».
Название Gestalt — не метафора, а методологическая заявка.

## 5. Ключевая развилка: идиография vs номотетика

- **Номотетический путь** (Big Five-стайл): фиксированная сетка черт, всех меряем по ней.
  Точно, сравнимо — но обезличенно; чат-логи — плохой материал для психометрии;
  итог = «профиль Honcho в типизированных полях», т.е. та же примитивность.
- **Идиографический путь** (Келли): система конструктов **данного** человека.
  Не «открытость 6.2/10», а «оценивает новое через призму "стабильность vs новизна",
  которую сам однажды сформулировал». Профиль = граф личных конструктов с evidence.
  Дороже, но это и есть «прокачанный профиль», которого ни у кого нет `[ПРЕДЛОЖЕНО]`.

Рабочее разрешение: **ядро — идиографический граф конструктов; поверх опционально —
номотетические проекции** (Big Five-фасеты как «линейки» для enterprise: HR-аналитика,
сравнение, дашборды). Ядро → сообществу (open), проекции → enterprise-монетизация.
Монетизация ложится в теорию, а не притягивается.

## 6. Профиль как предиктивный инструмент (Деннет)

Модель пользователя — не диагноз, а инструмент предсказания (реакций, предпочтений).
Следствия:

- этика: мы не «ставим оценки личности», мы ведём рабочую модель для лучшего сервиса;
- метрика качества портрета: не «верна ли черта», а **«улучшает ли модель предсказание»** —
  закрывает вопрос о метрике качества психопортрета (принято: **Р12**, док `11 - Предиктивная метрика портрета.md`);
- фидбек-луп из дизайн-заметок = проверка предиктивности: рекомендация — гипотеза модели,
  принятие/отклонение — измерение; «убить инсайт» — тоже сигнал.

## 7. Практические следствия для архитектуры

1. Два типизированных подграфа одной памяти: семантическая память (`WORLD`: факты, онтологии)
   и модель человека (`PSYCHE`: идиографический граф конструктов). Один движок; графовый доступ —
   за SPI (Р7: pure PG по умолчанию).
2. Онтологическая дисциплина (онтологии, evals — по опыту cognee, `../research/12` §12.5)
   применяется к домену PSYCHE: таксономия конструктов вместо таксономии сущностей документов.
   Этого не делает никто `[ПРЕДЛОЖЕНО]`.
3. Позиционирование: единственный Java-native memory engine с theory-of-mind профилем
   (идиографическим) и ontology-grounded точностью (**Р15**, §12.7).

## 8. Терминология проекта

> Канон словаря (**Р22**): термин обязан иметь дисциплинарный источник (§8.1/§8.2) либо заявлен именем-брендом с прототипом (§8.3). Новые термины вводятся только здесь; остальной корпус ссылается, не чеканит.

### 8.1 Из психологии и нейронауки

| Термин | Источник | Берём | Отвергаем / ограничиваем |
|---|---|---|---|
| Конструкт | Келли, «Psychology of Personal Constructs» (1955) | ось как инструмент антиципации; система конструктов **данного** человека — онтология PSYCHE (09) | repertory-grid как обязательный инструмент (v2+, Р12) |
| Эпизодическая / семантическая память | Тульвинг (1972) | разводку `Message` / `Fact` | процедурную память (вне контура v1) |
| Реконструкция по схемам | Бартлетт, «Remembering» (1932) | память = реконструкция, не воспроизведение; портрет = целое из следов (§4) | «выборку фактов с high-confidence» как модель памяти |
| Консолидация во сне | нейронаука памяти (systems consolidation) | двухстадийность: быстрая запись → медленная фоновая реорганизация | буквальную физиологию: наш «сон» — джоба, не биология |
| Encoding (кодирование) | Тульвинг / Аткинсон–Шифрин | имя онлайн-стадии памяти (сек) | многостадийные буферы (sensory/STM) как обязательство |
| Ассимиляция / аккомодация | Пиаже | интерпретацию обновления уверенности / supersession-цепочек (§Q2) | полный цикл как v1-обязательство (Р12) |
| Big Five | психология личности (Коста–МакКрей) | номотетические проекции — enterprise-слой (Р4) | как ядро: обезличено, чат-логи — плохой психометрический материал (§5) |
| False memory | Лофтус (DRM-парадигма) | мишень контрольной оси: уверенное «знание» того, чего не было = leak (11 §4, Р14) | — |
| Forgetting curve / decay | Эббингауз (1885) | затухание как функция неиспользования → ranking-bias (Н10(д)) | деструктивное забывание: floor, данные не стираем |
| Filler items | экспериментальная методология | нейтральные ходы между фактом и точкой измерения (filler-инвариант, Р14) | — |
| Идиографический / номотетический | Виндельбанд (1894) / Оллпорт | разводку ядра (граф конструктов) и проекций (Р4) | психометрическую «истинность» черт как мишень метрики (11 §5) |
| Интенциональная позиция | Деннет (1987) | модель юзера = предиктивный инструмент, не диагноз (§6) | диагностическую интерпретацию портрета |
| Theory of Mind | social cognition | PSYCHE как предиктивная модель человека — интенциональная позиция (§6, 07) | «модель человека = все данные о юзере»: биография и состояние юзера — объекты мира (WORLD, 10 §3.1) |

### 8.2 Из инженерии

| Термин | Источник | Берём |
|---|---|---|
| valid_time / би-темпоральность | Снодграсс, temporal databases (TSQL2) | факт живёт во времени действия; transaction_time отдельно (Р5) |
| Supersession | SCD Type 2 (Кимбалл) + belief revision (AGM, 1985) | смена истины = **статус + история**, не удаление (Р6) |
| Watermark | stream processing | маркер прогресса для инвалидации PortraitSnapshot (Р19) |
| Materialized view / snapshot | СУБД | PortraitSnapshot = проекция, не источник истины (Р19) |
| Golden set (golden master) | QA-практика | эталонный набор + CI-регрессия (Р12, Р14) |
| Uplift / парная абляция | ML-экспериментатика | lift = Δ точности плеч с одним отличием (наличие портрета) (11 §3) |
| LLM-as-judge (pairwise) | Chatbot Arena / MT-Bench | судейство парных сравнений; шум гасим пулом судей и калибровкой (11 §3) |
| Reconciliation | eventual consistency / event sourcing | фоновую сверку слепка с источником (Р10, Р19) |
| TTL, RLS, fail-open, coalescing, lease/backoff/poison | распределённые системы, PostgreSQL | как есть (Р9–Р11, Р19) |
| Scope (радиус видимости) | DI-скопы (session/request scope) | иерархию радиусов SESSION/PROJECT/USER (Р13) |

### 8.3 Имена-бренды (наш смысл шире прототипа — заявлено явно)

| Имя | Дисциплинарный прототип | Наш смысл | Статус |
|---|---|---|---|
| Dreaming | консолидация во сне (нейронаука) | фоновая когерентность фактов, каденс часов: supersede / merge / synthesis-инварианты (13, §12.7) | бренд, не физиология |
| Gestalting | схемы Бартлетта + замыкание гештальта | индукция паттернов и осей из массы фактов, каденс дней (13) | бренд |
| PSYCHE / WORLD | модель человека в ToM; наблюдение vs инференция (оценка личности: данные ≠ выведенные черты) | домен = **вид знания, не объект**: инференс о личности (PSYCHE) vs наблюдаемое о мире, включая юзера как объект — биография, состояние, договорённости (WORLD); граница — 10 §3.1 | бренд доменной оси |
| Прескриптив | recommendation + feedback loop (recsys) | гипотеза портрета, предъявленная юзеру; принятие / отклонение / kill = измерение (11 §4, L3) | бренд |
| L1 / L2 / L3 | offline eval / online A/B | сорта точек: выбор / ответ / живая реакция (11 §4) | краткие метки, определены в 11 |
| emerging → active | дифференциация (ортогенетический принцип Вернера) | жизненный цикл оси: кандидат → подтверждена, порог K (Н4/Н6) | бренд статусов |
| AU / AA / UA / UU | направление моделирования в ToM | матрица наблюдения: кто кого моделирует (07) | бренд нотации |

3. Критерий: термин должен быть узнаваем специалисту психологии или инженерии; приватный ярлык без прототипа — дефект канона.
