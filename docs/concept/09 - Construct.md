# Gestalt — 09: Construct (основа домена)

> Дополняет: `06` (теория: Келли), `07` (Actor/наблюдатели), `../research/12 - Аналоги memory-проектов.md` §12.2 (усиление, surprisal).

## 1. Принцип: конструкт = привязка к человеку и его смысловым осям

Construct — главная сущность домена: **вторичный порядок над фактами PSYCHE**,
модель того, *какими осями* observed оценивает мир. Отвечает на вопрос «почему у него такие
предпочтения», а не только «какие они».

Граница с фактами: факт WORLD (про мир) конструктом быть не может — конструкт всегда
**принадлежит** observed (чьи это оси). Мир — объект, оцениваемый через оси.
Факты WORLD могут выступать объектами в conditions («в инструментальной базе…»), но не конструктом.

Синоним «ценность» для оси — отклонён: сужает (ось может быть и ценностью, и стилем,
и способом категоризации; у Келли — прежде всего инструмент антиципации).

## 2. Расщепление сущности: Axis vs Instance

Келли разделяет ось и положение человека на ней. У нас:

- **ConstructAxis** — определение биполярной оси («стабильность vs новизна»).
  Переиспользуемая, канонизируемая, иерархическая.
- **ConstructInstance** — положение *конкретного* observed на оси + evidence + время + дрейф.

Зачем:
1. ядро остаётся идиографическим (оси не навязаны, а *обнаруживаются*);
2. дисциплина cognee: синонимичные оси канонизируются слиянием (entity resolution для психики);
3. будущее (v2+): словарь канонических осей → community-реестр (монетизационный крюк, принципы не ломает); в v1 seed-словарь отвергнут — у рантайма нет потребителя, идиографичность не нарушается (Н4/П1).

## 3. Схемы (черновик)

```
ConstructAxis {
  id, poleA, poleB,                  // «стабильность» | «новизна»
  description, status,               // active | merged(→target)
  parent: ConstructAxis?,            // иерархия: ← «отношение к инструментам»
  breadth                            // loose↔tight (Келли): широта применимости
}

ConstructInstance {
  id, axis → ConstructAxis,
  observed → Actor,                  // чьё положение
  position,                          // на оси A↔B (со confidence)
  conditions,                        // ситуационность: «в tooling», «в языке»
  confidence, valid_time, system_time,
  evidence: [Fact/PSYCHE],           // lineage ≥ 2 (ко-подтверждение)
  status: emerging | active | drifted | retired
}
```

Инвариант: конструкт — **материализуемый производный слой** над пулом фактов
(пересобираем по lineage) → ошибка индуктора не портит пул. Портрет = срез активных Instance.

## 4. Жизненный цикл: события → переходы

| Событие | Переход/изменение | Теория |
|---|---|---|
| 1 факт PSYCHE намекает на ось | Axis + Instance в `emerging` (не читается) | кандидат |
| 2-й независимый факт (возможно др. observer — индукция Dreaming) | → `active` | ко-подтверждение |
| согласный факт | confidence ↑ (reinforce) | ассимиляция |
| противоречащий факт | (а) уточнение `conditions`; (б) проактивная интерференция: появление гипотезы альтернативного полюса в `emerging` (активный полюс не сбрасывается) | аккомодация / интерференция |
| устойчивый дрейф полюса | `drifted` при преодолении порога устойчивости нового lineage (K ≥ 2) + интервал старого полюса в valid_time (старый опыт не стирается в ноль: несгораемый минимум, 17 §3) | дрейф (ретроактивная интерференция) |
| прямой statement юзера | быстрый дрейф (высоковесовый факт, мгновенно преодолевающий порог K) | self-perspective |
| «убить инсайт» | `retired` + мета-факт через Encoding | фидбек-луп |
| две активных оси семантически совпадают | merge осей, union lineage | канонизация |
| противоречие observers | Contradiction на уровне фактов; вес по recency + независимым авторам | без усреднения |

Положение (position) вычисляется детерминированно из полярностей/уверенности evidence —
LLM нужен только для именования оси (короткий вызов, вход — 5–10 фактов).
Confidence ~ f(число независимых фактов, независимых observers, recency, полярность).
Затухание (recency) следует единой кривой затухания с несгораемым минимумом (17 §5): старый опыт сохраняется в латентной истории, уступая активный приоритет свежим подкреплениям.
Salience ~ позиция в иерархии (superordinate оси объясняют больше поведения).

## 5. Связи

```
Message ──provenance──► Fact/PSYCHE ──evidence(lineage≥2)──► ConstructInstance ──axis──► ConstructAxis
                           │  ▲                                  │                        │ parent
                           │  └─ Contradiction ◄─(факт-факт)      ├─► PortraitSnapshot
                            ▼                                     ├─► Prescription → фидбек → Encoding → мета-факт
                        Fact/WORLD ──(объекты в conditions)──►    └─► PortraitDelta (drift/новые/retired)
```
