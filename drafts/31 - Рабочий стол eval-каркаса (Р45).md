## 1. Что построено

- **Конвейер** `eval/` (Gradle: `./gradlew -p eval run -Pargs=…`): `replay` (инжест → экстракция → дедуп → слепки; чекпоинты в БД, повтор — 0 LLM) → `lme` (генерация точек LongMemEval) → `wcheck` → `arms` (плечи A/B) → `oracles` → `report`; `all` — весь конвейер. Общая схема каркаса и потоков данных — [`docs/spec/eval/архитектура-каркаса.puml`](../docs/spec/eval/архитектура-каркаса.puml).
- **Viewer** — `EvalViewerTest` (JUnit + HttpServer, тег `viewer`, запуск из IDE): точка-центричный — досье точки (таймлайн префикс→W0→окно→M→будущее, W-проверка, coverage, истина, A/B-карточки с вердиктами), режим лога разметки; чтение с диска на каждый GET.
- **Калибровка (E2-PC, LongMemEval):** n=63, pass A 83% vs pass B 35%, lift +48 pp, McNemar exact p ≈ 1,9·10⁻⁹, B-only = 0, encoding-miss 1/63. Прибор работает. Детали и границы валидности — `docs/research/27`.

Решения: (а) эмбеддим trigger точки; (б) отбор — глобальный top-K по всем секциям без порога косинуса (порог — по боли после рана), вывод — в исходной секционной структуре; (в) сортировка — similarity DESC, tie-break reinforcement DESC, затем createdAt; (г) стартовый бюджет **K = 50 фактов** (~2–2.5K токенов против 19–33K: 30 — риск подрезать иглы с парафразной дистанцией statement↔trigger, 100 — возвращает шум без заметного recall-выигрыша; K — параметр селекции в `answer_fp`, перебор 30/50/100 дёшев — слепки/факты/эмбеддинги переиспользуются, перезапуск только arms ~7 мин); (д) нет embeddings (база без pgvector) → fail-fast рана, не тихая деградация (ADR 24 §9); (е) параметры селекции (модель/размерность/K/порог/tie-break) — в `answer_fp` по 35 §2.3; (ж) тесты — юнит селектора на фейковых векторах (top-K/порядок/tie-break/пустой слепок), HTTP-граница не тестируется (конвенция); (з) после рана стартовые константы — одной строкой в 35 §1; (и) backfill — этап `embed`: идемпотентен (NULL-строки), батч 32, прогон в runs со стадией `embed` (миграция sql/009), экономика — llm_calls без токенов (`/embeddings` usage не отдаёт). Реализовано 2026-09-20 (`DigestSelector` (portrait) + врезка `Arms` + `answer_fp` selection-строка (входит только при включённой селекции — без неё fp байт-в-байт доселекционный) + `configSnapshot` + 12 юнит-тестов селектора; сборка и IDE-инспекции зелёные), прогон E7 — впереди.
